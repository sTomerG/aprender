# Aprender

Spaanse werkwoorden stampen via invuloefeningen, met focus op persoonsvormen.

## Language

**Exercise**:
One practice unit: a single Spanish verb whose person forms the learner must fill in and submit together.
_Avoid_: Card, quiz, lesson, session

**Person form**:
A conjugated verb form for a grammatical person (yo, tú, él/ella/usted, nosotros, vosotros, ellos/ellas/ustedes).
_Avoid_: Conjugation (alone), ending, answer row
